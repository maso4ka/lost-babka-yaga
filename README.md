# 🌲 LOST BABKA YAGA

## The Forgotten Forest

Говорят, что в этом лесу исчезают не только люди,
но и данные.

Один программист попытался раскрыть тайну Бабы-яги,
но бесследно пропал.

Перед исчезновением он оставил послание.

Леший утверждает:

"Не всё, что существует в лесу, можно увидеть.
Не каждый след лежит на земле.
И не каждое послание живёт в файле."

## Твоя задача

Найди последнее послание пропавшего программиста.
